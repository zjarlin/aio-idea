# 首屏性能验收：2026-09-12

## 已发布行为

- 首页 HTML 同时携带本次实时鉴权得到的权限与目录。Wasm 启动直接消费快照，首屏额外启动 API 请求从两次减少为零。
- HTML 使用 `Cache-Control: private, no-store`，忽略 HTML 条件缓存。快照 JSON 转义左尖括号，不能结束脚本节点；不写入 localStorage。
- 后续目录轮询通过 `/api/runtime/bootstrap` 完成一次鉴权。ETag 未变化返回 304，权限、租户、注销仍每次重新校验。
- 请求及正文读取分别受同一个 8 秒截止信号约束，最多重试一次。失败后可重试；后台失败保留当前工作区，焦点和定时轮询不取消进行中的请求。
- JS、Wasm、CSS 提前下载。指纹静态资源采用一年 immutable 缓存，提供构建时 gzip 副本，鉴权 API 与插件票据资源不使用此公开缓存。
- 全局样式固定在应用根节点，避免临时加载页卸载时取消样式注册。验收以工作区布局样式生效为准，同时记录 DOM 出现时间。

## 测量结果

部署前 252 本机鉴权接口约 3.16–4.81 ms，目录约 4.94–7.96 ms。公网基线两次超过 60 秒仍未出现工作区，且尚未发出鉴权 API 请求；主要等待发生在 DNS、JS 和 Wasm 下载。不能把这些时间解释成密码验证开销。

最终 Wasm 为 3,437,990 字节，gzip 为 1,262,684 字节，减少约 63%。缓存重载时 JS 和 Wasm 的 `transferSize` 均为 0。首页响应中鉴权约 0.8–1.3 ms，目录约 1.5–5.3 ms。

| 本机公网浏览器采样 | 桌面冷启动 | 桌面缓存重载 | 移动冷启动 | 移动缓存重载 |
| --- | ---: | ---: | ---: | ---: |
| HTTP/1.1 对照，完整四项通过 | 18.621 s | 1.412 s | 25.998 s | 0.529 s |
| 默认 HTTP/2，已完成截图的采样 | 22.129 s | 1.804 s | 45.417 s | 截图等待字体超时，未纳入 |

以上为工作区布局可见时间，不代表各业务页后台数据已经返回。首屏额外启动请求均为 0。浏览器使用既有 Playwright Chrome 配置，关闭 QUIC；HTTP/1.1 对照另行关闭 HTTP/2。采样受当时网络波动影响，不能用于承诺所有用户的固定加载时间。

后续默认网络复测仍出现 Wasm 下载超过 60 秒。代码已消除首屏鉴权往返和无变化资源下载，但公网冷启动并未完全解决；剩余瓶颈是静态资源的跨网传输和连接停顿。未修改全站 Cloudflare 协议配置或用户系统代理。

## 验证与证据

- 最新合并源码的服务端测试：53 通过，9 个需专用环境的测试默认跳过。
- 另行执行真实 PostgreSQL/HTTP 启动测试，通过：匿名访问、HTML 快照、304、权限撤销、租户切换、注销后禁止复用快照。
- HTML JSON 注入边界、压缩协商、静态缓存和 HTML 不缓存测试通过。
- 桌面/移动真实 Web 壳协议测试通过：HTML 快照零额外请求、无快照回退、请求头与正文挂起约 16.3 秒结束两次尝试、重试恢复、焦点不打断请求、后台失败保留页面、注销清理、样式实际生效。
- Compose 本地浏览器回归通过：切回约 29–32 ms，零重复挂载与资源下载，真实 canvas 像素变化、跨租户返回、版本更新和会话隔离均通过。
- 公网 KMP Counter1、0→1 计数、304 后保留 iframe、市场 README 图片在桌面和移动端均通过；canvas 改变像素分别为 29,700 和 11,041，页面脚本错误为 0。

公网功能复测通过显式的 252 出口访问原 HTTPS 站点，没有模拟 API、激活插件或修改市场安装。该出口仅用于分离本机直连传输波动，不能把它的通过结果当成直连冷启动性能已经解决。直连桌面功能也通过，直连移动首次下载曾超时。Compose 移动按钮采用现有验收脚本相同的稳定布局后坐标点击。

本地证据位于仓库 `target/startup-test/`：`before/` 与 `before-http1/` 为基线，`local/` 为协议测试，`verified/` 与 `verified-http1/` 为发布后的采样，`accepted/` 保留后续公网超时样本，`plugins/report.json` 和 `plugins/mobile-report.json` 为真实插件检查。`keepalive/report.json` 为 Compose 回归结果。中间失败样本没有删除。
