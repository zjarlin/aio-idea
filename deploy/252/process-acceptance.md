## 验证结果

- 宿主 56 项测试通过，9 项依赖独立环境的测试未在常规命令运行；Web 检查、Web release 和 glibc 2.17 服务端构建通过。
- 平台浏览器 SDK 6 项测试通过，运行支持 9 项常规测试通过。数据库绑定恢复与插件数据库角色隔离另外在真实 PostgreSQL 上通过。
- Agent 的真实 Memory Wasm、PostgreSQL、Rust 与 Pi 联合回归通过；隔离 Linux 镜像内 6 项 Pi 测试通过。
- 在 252 独立 PostgreSQL 集群恢复生产数据库副本，完成安装、停止并重启候选宿主、资料找回、秘密解密、桌面与手机视口验证。
- 演练拒绝伪造前台上下文、跨租户与跨用户调用、未声明插件服务、未批准模型地址及后台秘密读取；实际网络探针确认容器无直接出站，日志不含测试秘密。
- 正式接口验证加密收件、请求 ID 幂等、净化来源、独立秘密展示、零 token 本地检索与图谱激活。升级宿主后复用同一批资料，再次成功解密与召回。
- 正式浏览器完成桌面 1440×1000、手机 390×844 的聊天与图谱高亮像素检查，并通过 Compose 来源对话框展示测试凭据。控制台错误为 0；测试来源与会话已删除，图谱不再返回被删除的来源。

正式站最初出现 Compose 空白：隔离页面中的流式 Wasm 编译反压下载，300 秒仍未完成。公共 `sdk/web/wasm.js` 改为先读取响应副本，再把原响应交给原生编译 API，保留 MIME、HTTP 状态及编译参数校验。修复上线后，实际浏览器下载两个 Wasm 约需 7–13 秒；未放宽 iframe、CSP 或资产授权。资源只在当前加载中暂存，不持久缓存票据资源。

原始报告及截图位于 `target/component-delivery/agent-public/`、`agent-rehearsal/` 和 `chinese-names/`；Cookie、测试秘密和数据库备份不进入 Git。凭据展示截图只含本次生成的测试值。浏览器脚本使用 `AIO_COOKIE_FILE`、`NODE_PATH` 与 `AIO_URL`，`agent-process.cjs resume` 只恢复验收现场，本身不执行宿主重启。

正式空间尚未绑定模型。252 对已批准的 `https://api.openai.com/v1` 直连失败，broker 探针返回 502，主机直接连接也失败。未宣称真实生产模型问答或自动 wiki 编译已完成验收；模型调用链在受控测试中验证。

目前可以持续收件、隔离秘密、检索净化来源、显示激活图谱和按权限查看凭据。整理任务保留待处理状态，完成空间模型绑定并使宿主能够访问批准的模型地址后才会推进。更换模型地址需要同步调整插件声明和宿主允许列表，不赋予容器直接网络权限。
